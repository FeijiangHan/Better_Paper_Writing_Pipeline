# Better_Paper_Writing_Pipeline

下面介绍如何更好的用AI改论文。

首先，使用下面prompt让LLMs提问+解决问题
> 请你仔细理解和阅读这些图，理解我们可以给审稿人提供哪些信息，哪些是有利于体现我们方法优点的。如果你有不确定的实验细节和配置，请最后整理成问题，我可以把细节发给你你再继续补充 然后重构下面章节，按照ICLR spotlight标注，美式英语，保持清晰易懂，准确，连贯。尽量用简单高频词翻译，语法准确，专业术语和全文一致。 请你连贯的生成内容，每一句内部不要换行。

然后，输入问题，修正LLM的认知。并使用下面prompt重新写作
> 现在，给我提供润色后完整的\section{xxxx}；避免防御性写作，思考审稿人喜欢什么，会给什么加分，而不是过度防御。论文主要是展示我们严谨性和工作量+贡献的。

一般这两步以后LLMs能给出非常好的版本，没有细节误差，没有防御性写作
